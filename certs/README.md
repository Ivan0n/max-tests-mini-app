# Сертификат для Bot API MAX

`russian_trusted_root_ca.pem` — публичный корневой сертификат Russian Trusted Root CA.
Клиент `max_bot.py` добавляет его к стандартным доверенным CA только в своём
SSL-контексте. Системное хранилище компьютера и остальных клиентов не меняется;
проверки цепочки сертификатов и имени сервера остаются включёнными.

- Источник: [официальная раздача Госуслуг](https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer),
  [страница установки](https://www.gosuslugi.ru/crt).
- Загружен: 2026-10-29.
- SHA-256 сертификата в DER: `d26d2d0231b7c39f92cc738512ba54103519e4405d68b5bd703e9788ca8ecf31`.
- Действует до: 2032-02-27 21:04:15 UTC.

[Документация MAX](https://dev.max.ru/docs-api) требует этот CA для
`platform-api2.max.ru`. При замене сертификата скачай актуальный файл из
официального источника, проверь владельца, срок действия и отпечаток, обнови
эту запись и пересобери образ. Приватных ключей в этой папке нет.
